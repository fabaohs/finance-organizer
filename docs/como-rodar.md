# Como iniciar o projeto

## Requisitos

- Docker configurado
- Node - v22.20.0
- Pnpm - 10.15.1

## Passo a passo

1. Clone o repositório com `git clone https://github.com/fabaohs/finance-organizer.git`
2. Entre no repositório com `cd finance-organizer`
3. Rode o comando `pnpm install`
4. Inicialize o docker e rode `docker compose up`
5. 1. Para rodar somente o frontend `pnpm dev:web`
   2. Para rodar somente o backend `pnpm dev:server`
   3. Para rodar os dois juntos `pnpm dev`
